# Requisitos funcionais
1. [RF01]Registrar o estoque de cada produto: Manter o registro da quantidade de cada produto no almoxarifado
2. [RF02]Registrar as entradas e saídas no almoxarifado: O sistema deve permitir o registro de qualquer movimentação no estoque(seja de entrada ou saída)
3. [RF03]Registrar login: O sistema deve ser capaz de registrar o cadastro de cada usuario

# Requisitos não funcionais 
1. [RNF01]UX: O sistema deve ter interface intuitiva e ser de facil utilização do usuario
2. [RNF02]Acessibilidade: O sistema deve ter mecanismos para permitir que qualquer usuario consiga usa-lo
3. [RNF03]Segurança: O sistema deve ser ca´paz de proteger os dados do usuario

# Regras de negocio 
1. [RN01]Controle de dados e integridade: Os dados são protegidos e só o usuario os acessa
2. [RN02]Estoque e logistica: O sistema deve ser claro em relação a estoque e logistica
3. [RN03]Processos de aprovação: Cada movimentação deve ser aprovada antes de executada
